## 0. 一句话概述

一款基于**真实天文历法**的历法时间档案工具：输入出生时间与地点，输出**干支四柱、五行分布、节气时刻、真太阳时修正**等客观历法数据，并配「算法透明」让计算过程可复现，做传统时间文化的普及科普。

定位：**历法计算工具 + 文化科普**。非预测、非命理、非商业服务。

---

## 1. 解决的痛点（实用性）

市面上网络排盘工具结果经常互相矛盾，根源集中在四类技术缺陷：

1. **不传真太阳时** —— 出生地点东西经度不同，太阳真正过中天的时间不同，很多工具只粗略按「北京时间」换算。
2. **不处理子时换日** —— 23:00–01:00 出生的日柱/时辰在不同规则下会有差异，需在真太阳时下判定。
3. **节气算法粗糙** —— 节气用查表或低精度近似，误差可达小时级。
4. **结果不透明** —— 出了结果却不给依据，难以验证。

**本工具的解法**：

| 痛点 | 本工具做法 |
|---|---|
| 真太阳时 | 按经度偏移 + 均时差(EoT)校正到地方真太阳时，再据以判定时辰 |
| 子时换日 | 基于真太阳时判定时辰，规则明确、口径公开 |
| 节气时刻 | 天文算法迭代求解太阳视黄经，工程级精度 |
| 结果不透明 | 提供算法说明，口径与数据全部可对撞复现 |

**价值**：普通人无需天文/历法知识，输入出生时间与地点即可得到客观历法档案。

## 2. 创新性

1. **自研天文历法引擎**（本地纯函数，确定性可测）：
   - 太阳视黄经、节气时刻（天文求解）、均时差、真太阳时。
   - 年柱以立春为界、月柱以中气为界、基于真太阳时的子时换日。
   - 农历↔公历双向换算，内置中国行政区划「省 → 市 → 区县」经纬度库，前端静态离线性，不依赖定位权限。
2. **算法透明可复现**：结果区分「真实历法数据 vs 工具说明」；口径公开，可交叉复算。
3. **工程严谨**：核心与前端均为确定性纯函数，配单测 + 静态检查双门禁。

## 3. 用户体验（体验感）

- **输入友好**：出生日期支持公历/农历双模式；出生地点三级选择（省 / 市 / 区县），无需手填经度；另有「手动经度」高级项。
- **一目了然**：首页「今日天时」一屏展示干支 / 节气 / 日出 / 日落；排盘结果以干支柱 + 色块呈现五行分布。
- **引导与反馈**：生成过程有多步过渡与缓动动画；要点用模态说明。
- **克制可信**：统一色板、留白，信息分层清晰；一切结果标注「不含命运、吉凶或运气推算」。

### 4.2 关键设计

- **纯函数 & 确定性**：历法计算完全同步、无网络/无系统时区依赖；可单测、可精确复现。
- **真太阳时**：经度偏移 + 均时差(EOT) 校正；据真太阳时判定时辰与换日。
- **一次成型接口**：输入 → `computeArchive` 得到 `{four, tally, nayin, term, moon, trueSolar, lunar}` 统一档案对象。
- **合规设计**：内置经纬度库（不申请定位权限）、无支付 / 社区、全量文案无禁用词、免责与算法说明齐全。

### 4.3 精度口径（诚实声明）

- **节气时刻**：太阳黄经 15° 整倍二分求解；2024 全年 24 节气与公开历书 24/24 同日、时刻到分钟级。
- **四柱 / 纳音 / 五行 / 年立月界**：精确确定（干支柱已用稳定公历锚点对拍）。
- **农历月号与闰月**：基于 Meeus 朔 + 中气推得，年/月/闰**强断言全对**；
  朔日起算的「日内」在月初边界可能存在 ±1 天系统偏差（如个别春节日），已如实以 `approx` 字段标记，不影响月号/闰月/节气/四柱。
- **日出日落**：NOAA，工程精度 ±1 分钟；极昼/极夜返回 `valid=false`。

### 4.4 性能与体积

- 城市列表、农历表均为本地静态数据；无网络依赖，离线可算。
- 运行时无第三方重库，主包体积受控。
