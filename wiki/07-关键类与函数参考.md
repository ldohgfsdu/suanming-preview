## `miniprogram/lib/civilTime.js`

```js
export function resolveChinaCivilTime(y, m, d, hour, minute, foldChoice = null):
  // hour 非 0..23 整数 → { ok:true, unknown:true, state:'STANDARD', dstApplied:false }
  // GAP                 → { ok:false, state:'GAP', reason:'dst_gap', message }
  // FOLD 未选           → { ok:false, state:'FOLD', reason:'dst_fold_unresolved',
  //                          needsFoldChoice:true, message }
  // 其余                → { ok:true, unknown:false, state, dstApplied, foldChoice,
  //                          epochMilli, y, m, d, hour, minute, hourDecimal }
```

`hourDecimal = hour + minute/60`，是喂给 `computeArchive` 的形式。
返回的 `y,m,d,hour,minute` 已是**标准北京时间**分量。

防止科普文案与计算内核口径漂移。页面侧开关接线由

| `buildToday(y, m, d)` / `refreshClock` | 今日天时卡片 |
