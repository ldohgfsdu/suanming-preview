# 03 · 模块职责

## 1. 顶层目录

```
suanming-preview/
├── miniprogram/          ★ 生产主链：小程序页面 + 历法 JS 内核 + 云函数权威副本
├── cloudfunctions/       ▲ 架构契约留档（insight 的部署镜像副本）
├── engine/               ○ 目标层：TS 确定性历法（仅 lib/types.ts）
├── insight/              ○ 目标层：空目录
├── shared/               ★ 冻结契约：schema、版本、hash（typecheck + 测试引用）
├── scripts/              门禁与代码生成
├── tests/                单元测试 + E2E + 冒烟脚本
├── kotlin-ref/           Kotlin 参考实现（跨语言 hash 对拍）
├── docs/                 执行轨工作文档（审查报告、报名备案、AI 接入）
├── .github/workflows/    唯一 CI 入口
├── wiki/                 本 Code Wiki
├── .tmp/                 本地缓存与探针脚本（gitignore，不入库）
└── dist-test/            测试构建产物（gitignore）
```

## 2. `miniprogram/` —— 生产主链

### 2.1 入口与配置

| 文件 | 职责 |
|---|---|
| `app.js` | `App()` 入口。`onLaunch` 中初始化 `wx.cloud`；`cloudEnvId` 留空时全站自动走本地规则降级路径，功能不中断 |
| `app.json` | 8 个页面注册、暗黑模式（`darkmode: true`）、`themeLocation`、`lazyCodeLoading`、相册写权限声明 |
| `app.wxss` | 全局样式与主题变量；就地科普（`.info` / `.culture-inline*`）在两页共用的样式 |
| `theme.json` | 深色/浅色主题变量（`@navBg` / `@navText` / `@pageBg`） |
| `sitemap.json` | 微信索引配置 |
| `project.config.json` | 开发者工具工程配置：appid、libVersion 3.6.2、`cloudfunctionRoot: cloudfunctions/` |
| `project.private.config.json` | 本地私有配置（gitignore） |

### 2.2 页面 `pages/`

| 页面 | 文件 | 职责与要点 |
|---|---|---|
| `index` | `index.js` 843 行 | 输入中心。公历/农历双模式、时辰选择（精确到时/分或「时辰未知」）、性别、省市区县三级地点、高级手动经度。含「今日天时」卡片（北京口径 + 北京坐标）。生成档案前做夏时制 GAP/FOLD 探测与真太阳时跨日二次确认。负责写入 v2 历史存储。底栏含科普入口 `goCulture` |
| `result` | `result.js` 321 行 | 档案展示 + AI 解读触发 + 保存分享卡片（canvas 600×760，含深色配色分支）。会话级 AI 缓存。**就地科普**：四柱/农历/真太阳时/修正量/五行/节气/月相旁的 ⓘ 就地展开条目摘要（开关语义见 `lib/culture-data.js` 的 `cultureToggle`） |
| `today` | `today.js` 201 行 | 今日天时独立页。北京时间 + 北京坐标统一口径；含 12 时辰五鼠遁时柱表 + 当前节气民俗说明（`TERM_INFO` 24 条）。同样带就地科普 ⓘ 锚点 |
| `terms` | `terms.js` 94 行 | 全年 24 节气时刻，按四季分组，标注「节/中气」与月建地支。年份切换走 ActionSheet（规避 6 项上限，逐档走 1900–2100） |
| `history` | `history.js` 86 行 | 本地历史档案：列表、单条删除、清空、复用（回填首页全部输入） |
| `about` | `about.js` 10 行 | 纯静态合规页（免责声明 / 算法说明），无任何计算 |
| `culture` | `culture.js` 64 行 | 传统文化科普库：全量条目列表 + 关键词检索（「与」语义）+ 分类筛选，纯内容页零计算 |
| `culture-detail` | `culture-detail.js` 41 行 | 科普条目详情：定义 / 渊源 / 属性 / 数据表 / 分节详解 / 关联概念（`redirectTo` 防返回栈堆叠） |

每个页面目录含 `.wxml`（结构）+ `.wxss`（样式）+ `.json`（页面配置）。

| `chinadst.js` | 262 | 中国夏令时 1986–1991（12 次切换硬编码表）、墙钟状态分类、gap/fold 解析、时区-经度自洽降级契约 |
| `civilTime.js` | 73 | 墙钟 → 标准北京时间（UTC+8）的归一化门面，含未知时间短路 |
| `lunar.js` | 42 | 公历 → 农历（跑 `LUNAR_TABLE`） |

| `lunar-table.js` | ~55K | 构建期生成的朔月表 `[year, month, leap, startJDN, len]`，1900–2100。**生产实际加载的文件** |
| `lunar-table.json` | ~55K | 上表的 JSON 镜像。**无任何生产代码 import**，仅供 `_emit-lunar-table.mjs` 落盘备查 |
| `place.js` | ~61K | 全国省级/地级/区县名称 + 地级行政中心坐标（`DATA` 单表） |

## 3. `shared/` —— 冻结契约层

| 文件 | 职责 |
|---|---|
| `protocol/enums.ts` | 领域枚举：`SolarTimeMode`（3 值）、`DayBound`（2 值）、`CalendarKind`（2 值）、`DegradeReason`（6 值）。全部 ASCII UPPER_SNAKE_CASE |
| `protocol/versions.ts` | 版本标识聚合 `PROTOCOL_VERSIONS`：hash 契约 / schema / Core 算法 / chart / facts / Preview 引擎 |
| `domain/archiveDocument.ts` | S-4 ArchiveDocument schema v1 双 hash 侧代码契约：`ArchiveInput`、`INPUT_HASH_KEYS`(14)、`DOC_HASH_KEYS`(19)、scope 组装与断言、`computeInputHash` / `computeDocHash` |
| `hash/hash.ts` | `computeHash()` 入口：递归断言树（P-1…P-8）→ canonical → UTF-8 → SHA-256 → `sha256:<hex>` |
| `hash/canonical.ts` | Canonical JSON 序列化（RFC 8785 JCS + 4 条 Delta）、ASCII key 排序、字符串转义、重复 key / 非 ASCII key 断言 |
| `hash/quantize.ts` | `Q(v, d)` DEC(d) 定点量化（远离零点四舍五入，10^d 常量表，禁 `Math.pow`） |
| `hash/normalize.ts` | Unicode 白名单 + NFC 归一化（白名单先行拒绝，再做 NFC，再验幂等） |
| `hash/fingerprint.ts` | 环境指纹 `EnvFingerprint`（node / unicode / icu / tz / lang / lcAll / hashContract） |

## 6. 权限边界（架构合规红线）

| 规则 | 执行方式 |
|---|---|
| `engine/` 与 `insight/` 不得互相依赖 | 人工评审（当前二者均未成为生产模块） |
| `shared/` 尽量无业务运行时依赖 | `shared/` 仅 import `node:crypto`；`miniprogram/lib/` 不 import `shared/` |
| `miniprogram/` 禁止把 Node 全局灌进生产前端 | `eslint.config.mjs` 为 `miniprogram/**/*.js` 单独声明 `WECHAT_GLOBALS` 白名单 |
| 云函数不接受客户端自报 docHash | `index.js:369` 自行计算 `serverDocHash()` |
| 小程序全部具名导入必须真实存在 | `tests/unit/import-contract.test.mjs`（静态门禁，2026-10-08 E2E 踩坑回归） |
