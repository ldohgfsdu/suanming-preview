### 备注模板（160 字，验证过在区间内）

```
本小程序为个人开发的传统历法计算与文化科普工具，根据用户主动填写的出生日期、时间与出生城市，在本地计算干支、二十四节气、农历、月相与真太阳时等客观历法事实，并对已算好的事实做传统文化背景解释。不收集用户上传内容，不提供付费、社交、评论或用户发布功能，不含预测、算命、占卜、吉凶判定类内容，全部数据仅在用户本机处理与保存。
```

**三个审核要点**：
1. 本地处理，不收集
2. 无付费 / 社交 / 评论 / UGC
3. 不含预测、算命、占卜、吉凶判定

## 高频驳回原因（按出现频率）

1. **应急电话填了自己手机号** → 系统直接拦截
2. **12381 短信超时未核验** → 整轮作废
3. **通讯地址只到路名** → 要求精确到门牌号
4. **信息手打有错字** → 复制粘贴而非手输
5. **人脸核身失败** → 扫码微信实名 ≠ 填写信息
6. **省份特殊要求未满足** → 承诺书 / 居住证
7. **服务类目选了玄学类** → 必须工具类
