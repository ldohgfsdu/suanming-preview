## 先搞清楚：两个号是什么

| | AppID | EnvId |
|---|---|---|
| 是什么 | 小程序的**身份证号** | 云开发环境的**地址** |
| 长什么样 | `wx` + 16 位，如 `wx1234567890abcdef` | `cloud1-` + 后缀，如 `cloud1-1g2h3i4j` |
| 在哪拿 | 微信公众平台后台 | 微信开发者工具（需先有 AppID） |
| 什么时候有 | **注册完立刻就有** | 开通云开发后才有 |
| 填到哪 | `miniprogram/project.config.json` 第 5 行 | `miniprogram/app.js` 第 7 行 |

**依赖关系**：必须先有 AppID → 用它导入开发者工具 → 才能开通云开发 → 才有 EnvId。

# 第一步：拿 AppID

## 情况 A：你还没注册小程序

先去注册，**注册成功瞬间就能拿到 AppID**。

## 情况 B：你已经注册了

### B.1 打开后台
浏览器打开 **https://mp.weixin.qq.com/** → 用你的微信扫码登录

### B.2 进入开发设置
左侧菜单 → 点「**开发**」→ 「**开发管理**」→ 「**开发设置**」

> ⚠️ 首次进入可能要扫码验证身份，按提示扫一下

### B.3 复制 AppID
页面最上方，「**AppID(小程序)**」这一行，右边有「**复制**」按钮

```
AppID(小程序)    wx1234567890abcdef    [复制]
```

**点「复制」**，然后粘贴到记事本先存着。

> 📌 小技巧：微信开发者工具登录后，AppID 也会自动显示，可以从那里复制，不用开浏览器

### B.4 顺便确认这两项
在同一页往下看：

- **基础库版本**：记下来，提审时要选 ≥ 这个版本
- ** AppID 权限**：确认显示「**开发者**」或「**管理员**」

# 第二步：拿 EnvId

⚠️ **必须有 AppID 才能做这一步。**

## 2.1 打开微信开发者工具

已安装在你电脑上：`C:\Program Files (x86)\Tencent\微信web开发者工具`

桌面有快捷方式「**微信开发者工具**」，双击打开

## 2.2 登录

- 工具打开后，**右上角**点「**登录**」（或直接弹二维码）
- **用你的微信扫码**，用**你的微信**确认
- 登录后，右上角显示你的**头像和昵称** → 说明登录成功

> ⚠️ 登录的微信号必须和该小程序的管理员一致，否则看不到云开发

## 2.3 导入项目

### 方式一：从后台一键导入（推荐）

1. 回到 mp.weixin.qq.com
2. 左侧「**开发**」→「**开发管理**」→「**开发设置**」
3. 往下滚，找到「**小程序 AppID**」那一栏
4. 点右边的「**开发者工具下载** / 「**导入项目**」链接
   - 会自动唤起开发者工具并带入 AppID
   - 弹窗问「是否新建项目」时选**是**

### 方式二：手动导入

1. 开发者工具首页 → 点「**导入项目**」
2. **目录**选：
```
C:\Users\42899\Desktop\微信小程序开发大赛\suanming-preview\miniprogram
```
   > ⚠️ 注意选`miniprogram` 这一层，不是 `suanming-preview` 这一层
3. **AppID**：粘贴你刚复制的
4. **项目名称**：随便起，如 `suanming-preview`
5. **后端服务**：选「**微信云开发**」← 重要，选这个开通更顺
6. 点「**确定**」

> 💡 **语言选项**：默认「JavaScript 增强」就好，不用改

## 2.4 开通云开发

1. 项目打开后，点**顶部工具栏**的「**云开发**」按钮
   - 一般在「编译」「预览」「上传」那一排的右侧或左���
2. 弹窗点「**开通**」
3. 填环境名称：`suanming` （随便起，只用一次）
4. 选套餐：
   - 「**免费**」或「**按量付费**」都行
   - ⚠️ 如果后台有「小程序成长计划」，参与后能升级成**6 个月免费个人版**
5. 点「**确定**」，开始创建
6. **等几分钟**（环境初始化，队列可能有点久）

## 2.5 复制 EnvId

创建完成后会自动打开云开发控制台，或者再次点顶部「云开发」按钮。

你会看到左上角或顶部有个环境名，旁边是环境 ID：

```
环境名称  suanming
环境 ID   cloud1-1g2h3i4j5k     ← 这就是 EnvId
```

**点旁边的复制图标**，或者手动选中复制。

> 📌 EnvId 就是 `cloud1-` 开头那串，**不是** AppID，别搞混

## 2.6 建议顺手领资源（能省后续成本）

后台 →「**行业能力**」→「**小程序成长计划**」→「**参与计划**」

选已有环境 → 确认。可领：
- 混元文本模型 **10 亿 Token**
- 混元文生图 **10 万张**
- **6 个月**个人版云开发环境

另外大赛官方的 **1B Coding Plan Token** 走另一条路：https://chatapi.weixin.qq.com/

# 常见问题

| 症状 | 原因 | 解决 |
|---|---|---|
| 后台看不到「开发」菜单 | 菜单需展开 | 左侧菜单**点最上面的**「开发」才有下拉项 |
| 开发者工具里没有「云开发」按钮 | 后端服务选错了 | 重新导入项目，后端服务选「微信云开发」 |
| 开通云开发提示无权限 | 登录的微信号不是管理员 | 用**管理员微信**扫码登录 |
| 云开发按钮点了没反应 | 项目未成功导入 | 检查目录是否选对、AppID 是否填了 |
| EnvId 在哪找不到 | 控制台布局差异 | 云开发控制台**顶部**或**左上角**，环境名右边 |
| 开通要等很久 | 环境初始化排队 | 正常，等几分钟；超过 30 分钟再看 |
| 选「不使用云服务」了 | 导入时选错 | 重新导入，选「微信云开发」 |

# ⚠️ 关于"游客 AppID"

现在代码里是 `wx2dfa85a31cf906d1`，这是**占位用的游客 AppID**。

它能让你在开发者工具里**预览和调试**，但：
- ❌ 不能上传代码
- ❌ 不能提交审核
- ❌ 不能发布上线
- ❌ **不能提报比赛**

所以**必须换成你自己的真实 AppID**。
