# 第 1 步 · 备齐材料（先备齐，别边填边找）

**这一步是成败关键。** 管局驳回的头号原因就是材料不齐或信息不一致。

| # | 备什么 | 怎么备 | 常见错 |
|---|---|---|---|
| 1 | 身份证**正反面** | 手机相机**实拍**原件 | ❌ 复印件 ❌ 隔屏拍 ❌ 美颜 ❌ 有反光 ❌ 只拍到部分 |
| 2 | 通讯地址 | **精确到门牌号** | ❌ 只写「XX 路」（会驳回） |
| 3 | 备用联系电话 | **家人的或同事的** | ❌ 填自己手机号（系统直接拦截） |
| 4 | 邮箱 | 常用邮箱 | — |
| 5 | 银行卡 | 确认微信号已绑 | ❌ 没绑 → 人脸核身过不了 |

### 身份证拍摄标准

```
✅ 正确：平铺在白纸上，光线均匀，四角完整，字迹清晰
❌ 错误：拿在手里、复印件、屏幕翻拍、桌面有杂物、灯光反光、暗光
```

> 拍完用手机相册**放大看一遍**，字必须看得清。

> ⚠️ 失败常见原因：扫码微信号的**实名信息**与你填写的**不一致**。先核对这一条。

# 第 5 步 · 进入备案（核心开始）

## 5.1 进入口
后台 → 左侧「**设置**」→「**基本设置**」→ 找到「**备案**」区域 → 点「**去备案**」

> 新注册的小程序，首页可能直接有「去备案」按钮。

## 5.2 第一页：验证备案类型

| 字段 | 怎么填 |
|---|---|
| 主办者性质 | **个人** |
| 证件类型 | **居民身份证** |
| 所属地区 | 你的省 / 市 / 区（**实际所在地**） |
| 证件正面 | 上传身份证人像面 |
| 证件反面 | 上传身份证国徽面 |

上传完系统会**自动识别**姓名和身份证号 → **务必逐字核对**，不一致就手改

## 5.3 第二页：主体信息

| 字段 | 怎么填 |
|---|---|
| 主体名称 | 你的姓名 |
| 证件号 | 你的身份证号 |
| **通讯地址** | **精确到门牌号**，如「XX 市 XX 区 XX 路 XX 号 XX 室」 |
| 主体负责人 | **你本人**（个人主体必须本人） |
| 负责人手机 | 你本人手机 |
| **应急联系电话** | ⚠️ **填家人的号**，不能填自己 |

> 确实没有门牌号 → 在备注里写「通讯地址已为最详细」

## 5.4 第三页：小程序信息

| 字段 | 怎么填 |
|---|---|
| 小程序名称 | 自动带出，核对即可 |
| AppID | 自动带出 |
| **服务内容标识** | 选「**工具**」 |
| **前置审批项** | 弹窗里选「**以上都不涉及**」→ 确定 |
| **备注** | 复制下面这段（160 字，已验证在 20–200 区间） |

### 备注文本（直接复制粘贴）

```
本小程序为个人开发的传统历法计算与文化科普工具，根据用户主动填写的出生日期、时间与出生城市，在本地计算干支、二十四节气、农历、月相与真太阳时等客观历法事实，并对已算好的事实做传统文化背景解释。不收集用户上传内容，不提供付费、社交、评论或用户发布功能，不含预测、算命、占卜、吉凶判定类内容，全部数据仅在用户本机处理与保存。
```

> 📌 这段话是**管局审核的主要依据**，三个要点：**本地处理不收集** · **无付费社交 UGC** · **不含预测算命**
> 📌 AI 能力已如实写入（「对已算好的事实做文化背景解释」）。**不要隐瞒 AI 用途**，审核会问，如实写反而是加分项。

## 5.5 第四页：人脸核身

- 屏幕上会出现二维码 → 用**你本人微信**扫码
- 背景选**白色或浅色**，摘掉帽子/口罩，不闭眼
- 按提示张嘴/眨眼，完成识别

## 5.6 第五页：提交

- 阅读《互联网信息服务备案承诺书》
- 勾选「我已阅读并同意」
- 点「**提交**」
- ⚠️ **提交成功页截图保存**

# 第 6 步 · 等微信初审（1–2 工作日）

- 微信会查材料完整性和资质合规性
- 结果通过**站内信**或**模板消息**通知
- ⚠️ 期间**保持手机畅通** —— 平台可能回访，来电通常是 **0755** 开头
- 若被驳回 → 按提示改，重新提交（**驳回后审核时效变 7 个工作日**）

# 第 7 步 · 工信部短信核验（⚠️ 最关键，24 小时）

**这是整条链最容易翻车的地方。**

## 7.1 等短信
- 初审通过后，**主体负责人**和**小程序管理员**都会收到工信部短信
- **发送号码：12381**（或 00815）
- ⚠️ **别当垃圾短信删了**

## 7.2 立刻核验
1. 打开 **https://beian.miit.gov.cn/**
2. 输入短信里的**验证码**
3. 填**手机号**
4. 填**身份证号后 6 位**
5. 提交

## 7.3 时限
> ⏰ **收到短信后 24 小时内完成，超时整轮作废，必须从头再来。**

**提交备案后立刻设闹钟**，或请家人一起盯。

# 卡住了怎么办 · 常见问题速查

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 找不到「去备案」 | 未完成认证 | 先做第 2 步实名认证 |
| 备案类型选不了「个人」 | 可能已选过主体 | 检查是否已有企业主体信息 |
| 应急电话填不了 | ⚠️ 填了自己手机号 | 换家人的号 |
| 人脸核身失败 | 扫码微信实名 ≠ 填写信息 | 核对实名信息一致性 |
| 人脸一直失败 | 环境问题 | 换网络 / 换手机 / 更新微信 |
| 收到 12381 短信但链接打不开 | — | 用**手机浏览器**打开，可能要允许弹窗 |
| 短信超时了 | 24h 没核验 | 只能重头提交，重新走一遍 |
| 管局驳回：地址不详细 | 只写到路名 | 精确到门牌号，或备注「已为最详细」 |
| 管局驳回：信息不一致 | 姓名/身份证号有错字 | 逐字对照证件 |
| 驳回后要等多久 | — | 重新提交后审核 **7 个工作日** |
| 审核中想撤回 | — | 提交管局前可撤回，**审核中不支持** |

```text
1. 前端为微信小程序，运行于微信客户端内，域名、证书均由微信平台统一管理；

本方案书所载内容真实有效。如因内容失实、非法造成相应后果，本人自愿承担法律责任。

申请人（签字）：[签名]
联系电话：[手机号]
日期：2026 年 [ ] 月 [ ] 日
```

> 湖南电信申请人自行注册的境外域名不能备案（个人主体用不到；如有则需境内注册并实名）。
