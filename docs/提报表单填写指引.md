## 先看清：这是「提报作品」，不是「报名」

|   | 阶段             | 何时做      | 填什么          |
| - | -------------- | -------- | ------------ |
| ① | **报名**         | ✅ **现在** | 只有实名信息 + 选赛区 |
| ② | **提报作品**（截图这个） | 等上线后     | 6 项材料        |

**同一个页面，但两件事。** 报名不要求作品上线，所以先把报名做完，作品信息等上线再提交。

### 1. 参赛命题 ▼

**已默认选中**：`「与AI共生」— 来微信做个小程序`

> 只有一个选项，保持默认即可。

### 2. 作品名称

填：**`东方时间文化档案`**

> ⚠️ 必须是**公众平台上已审核通过的小程序名称**，不能自己另起。  
> 如果后台名称还没改成这个，先去后台改并重新提审。

### 3. 说明文档（必须上传 · PDF · ≤100MB）

上传文件：**`suanming-preview/docs/作品说明.pdf`**（0.46 MB，已生成 ✅）

> 重新生成：`python scripts/build-pdf.py`（一条命令出 HTML + PDF）
>
> 官方要求内容须含：功能简介 · 应用场景 · 解决的实际问题 · 技术开发方案 · 创新点  
> —— 文档已按此结构组织，且含「团队情况与成果声明」章节。

### 4. APPID

填：**`wxd58dc3b769e05f93`**

> 从公众平台「开发管理 → 开发设置 → AppID(小程序)」复制。  
> ⚠️ 三处必须统一：公众平台后台 / `project.config.json` / 此处。

### 5. 小程序二维码 ❌ **暂时填不了**

**必须等作品正式发布后**才能下载。

获取路径：公众平台 →「设置」→「基本设置」→「小程序码」→ 下载

> 这就是为什么不能今天提交——顺序不可能颠倒：  
> 报名 → 备案 → 提审 → **发布** → 下码 → 提报作品

### 6. 身份证件图片

上传：**居民身份证正反面**

- 手机实拍原件，四角完整、无反光、不隔屏、不美颜

### 7. 参赛授权书 ❌ 需要先下载

报名页 → 参赛授权书 → 点「**更多详情**」下载模板

**两种签法任选**：

- **PDF 在线签署**（推荐）
- 打印 → 手写签字 → 拍照上传

> ⚠️ 中国赛区用**中文版**模板  
> ⚠️ **必须用官方模板**，不能自己写  
> 📌 **现在就下好签好**——备案审核要 7-20 天，不急着等上线
