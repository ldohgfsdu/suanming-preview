## 1. 注册与主体（微信公众平台官网 mp.weixin.qq.com）

1. 用你的微信扫码登录，选「小程序」→「**注册小程序账号**」。
2. **类型**：个人开发 → 建议选「个人」主体（若无营业执照企业主体）。参赛一般个人即可。
3. **小程序名称**：建议「东方时间文化档案」或同义名（注意「档案」「历法」一般可过；避免「占卜/算命」类词）。
4. 完成**邮箱验证 + 手机号验证 + 个人实名/身份证认证**（这一步必须本人、真实信息，政务平台无法代办）。
5. 完成「**小程序管理员绑定**」（微信扫码授权管理）。

> ⏳ 个人主体注册+认证通常 1-3 天；备案会让总时长拉长，请尽快着手。

---

## 2. 获取你的 AppID 并替换占位

1. 登录 mp.weixin.qq.com → 左侧「开发」→「开发管理」→「开发设置」→ 复制 **AppID(小程序)**。
2. 打开 `miniprogram/project.config.json`，把 `"appid": "wx2dfa85a31cf906d1"` 替换成你的真实 AppID。
3. 微信开发者工具**重新导入**该目录（或右上角「详情/重新打开」），确认标题栏显示你的 AppID。

---

## 3. 类目与服务类目

1. mp.weixin.qq.com →「设置」→「基本设置」→「服务类目」→「选择类目」。
2. 建议类目（按审核口径，选取与「历法计算 + 文化科普」匹配的）：
   - 首选：**工具 > 信息查询**（或 **工具 > 效率**）
   - 备选：**教育 > 教育信息服务 / 生活服务 > 生活百科**
   - 若相关类目需资质证书，选不需资质的普通类目（个人小程序的开放类目有限，以平台可选为准）。
3. 避免：算命/占卜/星座玄学类目——本产品**不含**，也会被合规举报。

---

## 4. 隐私保护指引（新版本必配）

1. 编辑 `miniprogram/app.json`（已含）：
   ```json
   "requiredPrivateInfos": ["saveImageToPhotosAlbum"],
   "permission": { "scope.writePhotosAlbum": { "desc": "用于将生成的档案卡片保存到相册" } }
   ```
2. mp.weixin.qq.com →「设置」→「服务内容声明」→「用户隐私保护指引」→「填写」：
   - 是否收集用户信息：**仅处理用户在本地填写的信息（日期/地点/性别），不上传，本地存储**。
   - 声明「保存相册」用途：生成分享海报存档。
   - 勾选你实际用到的 API（saveImageToPhotosAlbum 等）。
3. 保存后，返回开发者工具刷新，确认无「未配置隐私」报错。

---

## 5. 在微信开发者工具中**提审版本**（最核心一步）

1. 打开微信开发者工具 → 打开第 2 步导入的项目。
2. 右上角「详情」→ 确认**基础库**版本 ≥ 该工程基于版本（libVersion 3.6.x 即可），编译无报错。
3. 真机预览：点「预览」，用你的微信扫码在真机跑一遍（重点验证**深色模式 + 分享卡片保存相册 + 全部 5 页**）。
4. 点右上角「上传」按钮 → 选版本号（如 1.0.0）+ 项目备注 → 确定，把代码上传到公众平台。
5. 记住生成的**版本号**。

---

## 6. 提交审核并发布

1. 回 mp.weixin.qq.com →「版本管理」→「开发版本」→ 找到刚上传的版本 →「提交审核」。
2. 填**审核备注**（重要，提高通过率）：
   ```
   作品为历法计算与文化科普工具：输入出生时间与地点（仅本地处理，不上传），
   基于真实天文历法（Meeus 天文算法 + 校准时区太阳时）得出干支、节气、月相、日出日落等可靠事实，
   不含任何预测、算命、占卜、吉凶判定等内容。提供今日天时、全年节气、历史档案与相册分享等纯工具能力。
   ```
3. 服务内容声明/隐私指引需先行配置（向导会引导）。
4. 提交后等审核（通常几小时~ 1 天）。回来可能需求：
   - 改类目 → 按第 3 步调整；
   - 补基础截图 → 按第 4 步真机截图补传。
5. **过审后**→「版本管理」→「发布」或「全量发布」。

## ⚠ 常见卡点提示

- **AppID 不一致**：开发者工具项目里、project.config.json、mp.weixin 后台三处必须统一。
- **隐私未配置上报**：若开发者工具报「requiredPrivateInfos」相关错误，先回到第 4 步完成平台侧隐私填写。
- **类目被拒**：换第 3 步备选类目重提，不要为了速度去选「玄学/算命」类（会命中禁用词红线）。
- **真机深色**：`prefers-color-scheme` 深色仅在真机可见，开发者工具模拟即可看大项，提审前务必真机扫一遍截图。
