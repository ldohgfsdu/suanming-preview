## 步骤 3 · 部署云函数（关键一步）

1. 在**文件树**里找到 `cloudfunctions` 文件夹
2. 展开 → 右键点 **`insight`**
3. 菜单里选「**上传并部署：云端安装依赖**」
   > **必须选「云端安装依赖」**，不是「上传并部署」
   > 这样云端会按 `package.json` 自动装依赖，本地不需要 `node_modules`

4. 等待上传完成（可能 1–3 分钟）
5. 完成后 `insight` 文件夹图标会变成**云朵图标**，说明部署成功

## 部署失败怎么办

| 报错 | 原因 | 解决 |
|---|---|---|
| 目录树看不到 `cloudfunctions` | 导入目录选错了 | 必须选 `miniprogram` 这一层 |
| 没有「上传并部署」选项 | 后端服务选了「不使用云服务」 | 重新导入，选「微信云开发」 |
| 部署报依赖错误 | 选了「上传并部署」而非「云端安装依赖」 | 换正确菜单重来 |
| 提示无云开发权限 | 登录的微信号不是管理员 | 用**管理员微信**扫码登录 |
| 调用返回 `cloud_unavailable` | `wx.cloud` 未初始化 | 检查 Console 是否有初始化日志 |
| 模型调用失败 | 环境未开通 AI 能力 | 云开发控制台 → AI 功能 → 开通 |
